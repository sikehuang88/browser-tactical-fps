# 对局核心玩法联调测试

协议级集成测试：以 Node 内置 WebSocket 直接驱动两个客户端，验证服务器权威玩法的完整闭环。

## 场景

1. **握手与队伍分配**：两客户端加入，A=进攻方、B=防守方。
2. **行动阶段 A 击杀 B**：A 朝向 B 开火 → 服务器射线命中头部 → 击杀播报。
3. **回合结算**：防守方全灭 → 进攻方胜，计分 1:0。
4. **A 安装炸弹**：A 走到 B 点按住 E（USE）→ 炸弹安装成功（40s 计时）。
5. **B 拆除炸弹**：B 走到炸弹点拆除 → 防守方胜，计分 1:1。

## 运行

```bash
# 终端 1：启动服务器（每个测试请用全新服务器实例）
cd server && cargo run -- --port 9000 --tick-rate 64

# 终端 2：跑测试（需要 Node ≥ 21）
node tools/integration/combat_test.mjs      # 击杀/结算/安装/拆除
node tools/integration/economy_test.mjs     # 购买/经济/投掷物
```

全部场景通过输出 `=== 全部通过 ===`。注意：两个测试会共用服务器对局状态，请勿在同一服务器实例上连续运行，跑完一个后重启服务器再跑下一个。
